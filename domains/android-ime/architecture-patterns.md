# Android 输入法架构模式

## 适用范围
- 适用于 Android 输入法项目
- 适用于已有输入法模块的增量开发
- 不适用于从零设计全新输入法平台的架构研究

## 核心立场
- 输入法是“宿主接线 + 输入状态 + 输入行为 + UI 渲染”的组合系统。
- 最容易失败的做法，是把这些职责混在一个超大类里。
- 最稳的演进方式，是先稳定骨架，再叠加词库、排序、UI 和宿主适配。

## 稳定规则
- 宿主接线层负责生命周期、`InputConnection`、`EditorInfo` 和系统输入法回调。
- 输入状态层负责输入模式、大小写、拼写缓冲、候选、分页、符号/数字状态。
- 输入行为层负责删除、空格、回车、选词、快捷键等行为。
- UI 控制层负责把状态映射成可渲染数据。
- 视图层只负责布局、绘制、交互事件回调，不负责业务决策。

## 推荐分层
- 宿主层
  - 输入法服务生命周期
  - 宿主输入框上下文
  - `InputConnection` 调用
- 状态层
  - 键盘模式
  - 拼写缓冲区
  - 候选状态
  - 符号/数字分页状态
- 行为层
  - 字符输入
  - 删除
  - 回车
  - 候选选择
  - 快捷键
  - 模式切换
- UI 控制层
  - 候选栏状态
  - 键盘渲染状态
  - 输入框类型到 UI 的映射
- 视图层
  - 顶栏
  - 候选栏
  - 键盘网格
  - 特殊键
  - 焦点与按压反馈

## 推荐演进顺序
- 先稳定输入状态和行为主链路
- 再拆词库、匹配器、排序器
- 再做宿主适配和编辑器回车兜底
- 最后做参考图对齐、视觉优化和复杂布局切换

## 稳定设计判断
- 拼写中的文本必须是系统一等公民，不是 UI 附属品
- 候选栏是状态投影，不应自己持有真实业务状态
- 符号键盘和数字键盘优先共用主框架，不轻易新开平行体系
- 视觉重构不应打散输入行为骨架
- 词库资产化不应反向污染输入服务主链路

## 常见反模式
- 在 View 里直接写提交、删除、编辑器动作逻辑
- 在 Service 里直接堆 UI 分支和布局状态
- 把拼写缓冲、候选、分页写成多个松散字段，没有统一状态入口
- 为了一个任务引入新的通用架构层
- 一边做宿主兼容，一边做词库升级，一边做 UI 重构

## 什么时候用
- 新建或接手 Android 输入法项目
- 判断某个输入法模块是不是已经耦合失控
- 写输入法任务之前
- 评估重构是否必要

## 不适用场景
- 当前任务只涉及很小的局部 bug
- 当前仓库已有更严格的项目内架构约束

## 来源
- 来自多个 Android 输入法类问题的稳定模式
- 当前已被 `StudyCustomInput` 这类增量演进项目验证

## 候选覆盖的双层模式

IME 候选覆盖能力分两层：数据层精确命中 + 代码层动态兜底。

- **数据层**：往词库补词条，索引自动派生（如 PinyinInitialsIndex 从 phrase 自动生成首字母索引）。精确匹配，排序优先级高。
- **代码层**：运行时动态组合（如首字母→音节扩展 + Composer 单字组合）。覆盖长尾，排序优先级低。

适用条件：
- 数据层覆盖的总是有限集（不可能预存所有可能词组）
- 代码层能覆盖的受限于组合空间和排序质量
- 两层叠加后：高频词精确命中、长尾词动态组合

**Why**: 纯靠补数据追不上用户输入习惯，纯靠动态组合排序质量不够。双层模式在高频精确 + 长尾可出之间取得平衡。

**How to apply**: 遇到候选覆盖缺口时，先评估是数据问题还是代码问题。如果词库有对应词条但索引没覆盖→补索引；如果词库根本没有→先补数据，再评估是否需要动态兜底。

## 纯简拼长词的首字母→音节扩展模式

当用户输入纯首字母串（如 `bjhyn`），且词库无对应词条时，可用首字母→音节扩展 + 现有组合器兜底：

1. 每个首字母扩展为 top-N 高频音节
2. 生成有限 SegmentPath（控制总路径数）
3. 喂给现有 SegmentedCandidateComposer 做单字组合
4. 结果以最低排序优先级追加

关键约束：
- 限制首字母长度范围（4-6 位）
- 限制每位扩展数（2 个音节）
- 限制总路径数（16 条）
- 仅在现有链路结果不足时触发
- 排序权重低于词库精确匹配

**Why**: 枚举所有音节组合会爆炸（5 位×17 音节 = 10^5），但只取 top-2 + 路径上限 16 可控。复用现有 Composer 避免重写组合逻辑。

**How to apply**: 其他 IME 遇到纯简拼长词无候选问题时，可采用同样模式。不要放大扩展数，先验证 top-2 的覆盖率和组合质量。
